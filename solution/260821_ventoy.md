```shell
lsblk # 分辨要安装 Ventoy 的 U 盘
sudo ventoy -i -g -r size /dev/sdx # 按提示操作即可
sudo ventoy -l # 显示 U 盘中的 Ventoy 相关信息
```
- -i —— 安装 Ventoy 到 U 盘中（如果对应磁盘已经安装了 Ventoy 则会返回失败）
- -g —— 使用 GPT 分区格式，默认是 MBR 格式
- -r —— 在 U 盘最后保留部分空间（可选，可以分区并格式化后使用）：
- - size —— 空间大小（单位是 MB）
